# 宣传片与封面

标题：**这座岛，想怎么折腾都行｜潮生岛**

36 秒，720p、30 FPS，H.264 / AAC。1080 帧来自真实 Godot 场景；脚本使用游戏同样的三维体素编辑、撤销和种植方法。海边山体是在录制前用塑形工具搭建的示范地形；没有用生成式视频替代游戏画面。

| 时间 | 操作与镜头 |
| --- | --- |
| 0–7 秒 | 同一近景连续向山内开凿，直到能从洞口看见另一侧海面 |
| 7–14 秒 | 切断石拱顶部；保持镜头位置，调用游戏撤销，恢复完整石拱 |
| 14–25 秒 | 从地面逐段向高处搭建；挖掉连接部分，留下真正悬空的体素地形 |
| 25–31 秒 | 在悬空岛上直接种树、种花，环绕展示洞口和浮岛 |
| 31–36 秒 | 完成后的全景，游戏名与下载入口 |

开凿、塑形、撤销与种植声按记录的操作时刻混入；音乐和海浪来自游戏原创资源。这里的悬空地形可保持悬空，游戏没有自动坍塌物理，因此影片没有展示或宣称坍塌。

封面：1920×1080 PNG，左侧大字「这座岛 / 想怎么 / 折腾都行」，右侧是实际场景的穿山洞与悬空森林。README 使用同版 JPG。封面和 MP4 均在 GitHub v0.3.1 发布附件中。

## 重新制作

准备原生 Voxel Tools 定制引擎、FFmpeg 及 Windows 微软雅黑字体。从项目根目录运行：

~~~powershell
.\godot-voxel.exe --path game --script ../tools/capture_promo.gd --fixed-fps 30 -- --promo-capture
.\tools\encode_promo.ps1
~~~

增加 --pilot 可先生成每秒一张的分镜图。完整录制输出到 media_work/frames_v2，动作时刻写入 media_work/actions.json。视频和封面输出到 media/TidebornIsland-Trailer.mp4、media/TidebornIsland-Cover.png。使用独立测试模式，不读取或覆盖玩家正式存档。字体仅在本地用于排版，不包含在下载包或源码仓库中。
