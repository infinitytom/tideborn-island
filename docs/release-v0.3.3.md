《小岛叠叠乐》v0.3.3：施工更顺手，夜里也看得清。

- 操作音效削弱尖锐高频，加入柔和起音与收尾，降低播放增益；连续操作最多每 190 毫秒触发一次，限制声音叠加。原有音量设置继续有效。
- 默认抬升增量增强，力度滑块仍可控制细节，悬空添加与开凿保持原有方式。
- 新增独立冷色月光与月亮，增加夜间环境补光，地形、树木和施工轮廓更清楚；晨昏照明仍连续过渡。
- 种子开始影响岛屿朝向、长宽、海湾、山体比例、河湖位置及泉眼、石拱和洞穴落点；修正不同种子沿用相同地形骨架、外观过于相近的问题。同种子可重现，旧存档保持原有地形；默认展示种子 260104 保留熟悉的小岛。
- 鼠标悬停显示半透明笔刷范围：绿色添加、红色开凿与右键减去土石，悬空预览位于实际指定高度。预览与编辑共用定位规则，全景模式隐藏预览；抬升仍按力度逐次累积。
- 主界面新增「我的世界」：新建或切换前自动保留当前岛屿，旧世界可打开、另存和确认删除。修复重启后直接新建世界覆盖原当前世界、打开旧记录时丢失当前世界的问题。
